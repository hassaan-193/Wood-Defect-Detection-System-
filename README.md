# Wood-Defect-Detection-System-
YOLOv8-based wood surface defect detection on the Nordic Timber Dataset (10 classes, 30 epochs, mAP@50: 0.587). Benchmarked against classical CV. Implements findings from Goycochea Casas et al., Forests 2026. Covers training dynamics, per-class AP, confusion matrix analysis, and deployment optimization.
